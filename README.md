# Task:1 Titanic Survival Prediction

Project Overview
* Predicts whether a passenger survived the Titanic disaster using machine learning.
* Demonstrates the complete classification workflow from data preprocessing to prediction.

Features
* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Feature encoding
* Model training and evaluation
* Survival prediction

Technologies Used
* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Google Colab

Dataset
* Titanic Dataset (`train.csv`)
* Features include Age, Sex, Fare, Pclass, Embarked, SibSp, Parch, and Survived.

Results
* Trained multiple classification models.
* Evaluated using Accuracy, Precision, Recall, and F1-Score.
* Random Forest provided the best performance.
